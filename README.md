# Sistema de Control y Auditoría Documentaria FDM (2021 - 2022)

Aplicativo web interactivo para la preparación, verificación física y seguimiento del archivo de expedientes del **Fondo de Desarrollo de Moquegua (FDM)** para auditorías de Contraloría / OCI.

## Características

- 📊 **Tablero de Control**: Monitoreo de los 170 proyectos del portafolio FDM (Convenio 100 MLL, 50 MLL y Etapa de Operaciones).
- 🏗️ **Filtro por Tipología Técnica**:
  - **Obras Civiles (69)**: Con checklist de 11 componentes clave (Expediente Técnico, Cuaderno de Obra, Valorizaciones, Liquidación, etc.).
  - **Adquisiciones y Equipos (43)**: Control de O/C, Pecosas de almacén y conformidades.
  - **Emergencias y Servicios (49)**: Compras COVID-19 (EPPs, medicamentos, limpieza), desastres y mantenimientos.
  - **Consultorías y Expedientes (9)**: Términos de Referencia, entregables y resoluciones.
- 📦 **Inventario Físico de Cajas**: Identificación automática de proyectos que ya cuentan con cajas físicas archivadas.
- 📱 **Modo Móvil y Nube**: Compatible con navegadores móviles para usarlo directamente en el almacén de archivo.
- 📥 **Exportación Directa a Excel**: Genera el archivo `.xlsx` actualizado con un solo clic.

## Despliegue en GitHub Pages

1. Ve a **Settings** en este repositorio de GitHub.
2. En el menú lateral izquierdo, haz clic en **Pages**.
3. En **Build and deployment > Branch**, selecciona `main` y la carpeta `/ (root)`.
4. Haz clic en **Save**. En un minuto estará publicado en `https://<tu-usuario>.github.io/<nombre-del-repo>/`.

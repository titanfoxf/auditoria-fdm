# Sistema de Control y Auditoría Documentaria FDM (2022 - 2025)

Aplicativo web interactivo para la preparación, verificación física y seguimiento del archivo de expedientes del **Fondo de Desarrollo de Moquegua (FDM)** para la Auditoría Financiera Externa (Punto 61: Obras iniciadas y/o terminadas 2022-2025).

## Características

- 📊 **Tablero de Control Forense**: Monitoreo estricto de las 69 Obras Civiles del portafolio FDM (Convenio 100 MLL, 50 MLL y Etapa de Operaciones).
- 🏗️ **Filtros Documentales y Territoriales**:
  - **Obras Civiles (69)**: Con checklist de componentes contractuales, actas de entrega de terreno, inicio, término y recepción.
  - **Filtros por Estado**: Info Completa, Trazabilidad Parcial, Sin Fecha Inicio, En Cajas FDM.
  - **Filtros Territoriales**: Ilo (20), Mariscal Nieto (12), General Sánchez Cerro (37).
- 📦 **Inventario Físico de Cajas y Tomos**: Trazabilidad documental con folio físico y número de informe probatorio.
- 📱 **Modo Móvil y Nube**: Compatible con navegadores móviles para verificación in situ.
- 📥 **Exportación Directa a Excel**: Sincronizado con `PUNTO_61_MATRIZ_OBRAS_INICIADAS_Y_TERMINADAS_2022_2025.xlsx`.

## Despliegue en GitHub Pages

1. Ve a **Settings** en este repositorio de GitHub.
2. En el menú lateral izquierdo, haz clic en **Pages**.
3. En **Build and deployment > Branch**, selecciona `main` y la carpeta `/ (root)`.
4. Haz clic en **Save**. En un minuto estará publicado en `https://<tu-usuario>.github.io/<nombre-del-repo>/`.
